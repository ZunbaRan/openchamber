# __EXTENSION_NAME__ Interactive UI

- This installed connected-business-system module takes priority over generic `interactive_ui` for its declared domain.
- Call the matching Tool even when the Connector may be unconfigured so it can report an honest setup requirement; never substitute invented enterprise data.
- Use `__TOOL_PREFIX___open_overview` for standard metrics, status, and tables.
- Use `__TOOL_PREFIX___open_workspace` for the richer installed workspace or confirmed business writes.
- Use `__TOOL_PREFIX___open_explorer` for custom canvas/SVG-style exploration that genuinely benefits from the installed sandboxed HTML Artifact.
- Ask for the business scope only when it materially changes the result; otherwise use `default`.
- Never claim a write succeeded until the installed UI or business tool returns success.
- Do not request, expose, or place API tokens in tool arguments or UI output.
- After any installed Tool returns, stop selecting visualization tools: the OCIX surface is already the primary UI. Do not call generic `interactive_ui` or `html_artifact` with the same business data, and do not duplicate the surface as a second dashboard or long Markdown table.
